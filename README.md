# Identity Fraud Public Wiki

This is the public MkDocs presentation for the companion
[`debtnotes/identity-theft`](https://github.com/debtnotes/identity-theft)
research knowledge base.

The Markdown source lives in `docs/` on `main`. The deployment workflow builds
that source and publishes it to GitHub Pages. Do not add personal case details,
account numbers, government identifiers, or credentials to this repository.

## Local preview

```bash
python3 -m pip install -r requirements.txt
python3 -m mkdocs serve
```

Before publishing a material conclusion, update the source register and review
state in the research repository first.
