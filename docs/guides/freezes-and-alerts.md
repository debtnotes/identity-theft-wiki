# Credit freezes and fraud alerts

Both are free protections for a consumer’s credit file. They are distinct from
commercial credit locks.

| Tool | What it does | Key limit |
| --- | --- | --- |
| Security freeze | Blocks prospective creditors from accessing the credit file. | It can also delay the consumer’s own new-credit application until lifted, and it does not stop every type of fraud. |
| Fraud alert | Tells creditors checking the file to take steps to verify identity. | It does not block a creditor from opening credit after verification. |
| Credit monitoring | Sends alerts about monitored changes. | It is detection, not prevention. |

## Security freezes

The CFPB says a freeze is free and must be placed with **Equifax, Experian, and
TransUnion separately**. It does not change a credit score. Existing creditors
and certain government entities may still access the file. See the CFPB’s
[security-freeze guide](https://www.consumerfinance.gov/ask-cfpb/what-is-a-credit-freeze-or-security-freeze-on-my-credit-report-en-1341/).

## Fraud alerts

An initial alert can last up to one year unless removed earlier. CFPB says an
extended alert, available with an identity-theft report, lasts seven years.
Contacting one nationwide bureau to place an alert triggers notice to the other
two. See the CFPB’s [identity-theft response guide](https://www.consumerfinance.gov/ask-cfpb/what-do-i-do-if-i-think-i-have-been-a-victim-of-identity-theft-en-31/).

For a fraudulent item already appearing in a credit report, a separate federal
process may allow a request to block identity-theft information. The facts and
required documentation matter; read [FCRA § 605B](https://consumer.ftc.gov/system/files/consumer_ftc_gov/pdf/fcra-605b.pdf) and use IdentityTheft.gov’s tailored steps.
